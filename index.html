How KNN works

01

Measure distance

Compare the test point to each labeled example. Euclidean distance is a straight line. Manhattan distance adds the horizontal and vertical steps.

02

Pick the k closest

The letter k tells the computer how many neighbors to ask. Changing k can change which points get a vote.

03

Count the votes

Each neighbor votes for its own class. The class with the most votes wins. In this lab, a tie goes to the class whose nearest voting neighbor is closest to the test point.
